Partie z fotky partiáře

Vyfoť zapsaný partiář. Claude (umělá inteligence od Anthropicu) ho přečte, každý tah se ověří podle pravidel a nejistá místa se ukážou ke kontrole. Výsledkem je partie ve formátu PGN.

Klíč k Claude API

Klíč získáš na platform.claude.com (Settings, API keys). Uloží se jen v tomto prohlížeči. Fotka partiáře se posílá ke čtení společnosti Anthropic, přečtení jednoho partiáře stojí obvykle 0,10 až 0,30 USD.

Fotka partiáře

Celý list rovně shora, ostře a bez stínu. Nejvýš 4 strany (třeba obě strany partiáře). Soubory jde sem i přetáhnout.
