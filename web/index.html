Partiář do PGN

Vyfoť nebo naskenuj zapsaný partiář. Claude ho přečte, aplikace ověří každý tah podle pravidel a nejistá místa ti ukáže ke kontrole.

Klíč k Claude API

Klíč získáš na platform.claude.com. Zůstává jen v tvém prohlížeči a posílá se jen přímo do Claude API spolu s fotkou. Přečtení jednoho partiáře stojí obvykle kolem 0,10 až 0,30 USD.

Fotka partiáře

Nejlépe celý list rovně shora, bez stínu a ostře. Fotka nebo PDF, nejvýš 4 strany (obě strany partiáře nebo víc listů jedné partie).
